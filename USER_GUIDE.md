# PROJECT ATLAS — User Guide & Science Fair Presentation Manual

## 1. Launching PROJECT ATLAS
- **Standard Launch (`run_atlas.bat`)**: Double-click `run_atlas.bat`. It launches a lightweight local server bound to `127.0.0.1:8080` and opens `http://127.0.0.1:8080/index.html`.
- **Direct Single-File Launch**: Open `dist/project_atlas_standalone.html` directly in Chrome, Edge, Brave, or Firefox.
- **No Internet Required**: Disconnect Wi-Fi/Ethernet at any time—every feature operates 100% locally.

## 2. Mouse & Keyboard Controls
### Mouse Controls
- **Left-Click + Drag**: Orbit / rotate camera around the current focus target.
- **Scroll Wheel**: Zoom smoothly toward or away from the target.
- **Right-Click + Drag**: Pan camera target across 3D space.
- **Single-Click Celestial Body**: Select the object and populate the Right Inspector Panel with verified NASA metrics.
- **Double-Click Celestial Body**: Smoothly fly the camera to focus on the selected world.

### Keyboard Shortcuts
- **`W` / `A` / `S` / `D`**: Free-flight camera translation (Forward, Left, Backward, Right).
- **`Q` / `E`**: Vertical camera movement (Down / Up).
- **`Shift` (Hold)**: 2.6x faster free-flight camera movement.
- **`Space`**: Pause / Resume orbital time simulation.
- **`R`**: Reset camera to the default Solar System overview.
- **`F`**: Toggle browser Fullscreen mode (ideal for projectors).
- **`Escape`**: Close active modal dialog or stop the automated Demo Mode.
- **`1` – `5`**: Quick view shortcuts (`1`: Solar System Overview, `2`: Inner Rocky Planets, `3`: Focus Earth, `4`: Focus Saturn & Rings, `5`: Deep Space Milky Way).

## 3. Navigation Modes (Left Panel)
1. **HOME**: Launch console and Solar System overview.
2. **SOLAR SYSTEM**: Full 8-planet + 5-dwarf-planet orbital simulation with Asteroid Belt, Kuiper Belt, and Conceptual Oort Cloud toggles.
3. **PLANETS**: Detailed planetary inspection, surface close-up view, and Saturn Ring Structure Inspector.
4. **MOONS**: Dedicated satellite explorer covering 18 moons and special Jupiter/Saturn system tour buttons.
5. **DEEP SPACE**: Barred spiral Milky Way visualization (`~26,000 ly` Solar System marker), Andromeda (M31) mode, and Messier nebula/cluster catalogue.
6. **MISSIONS**: 5 interactive guided journeys with 3D probe animation and stage telemetry.
7. **LABORATORY**: "What If?" physics sandbox (axial tilt, rotation speed, scale) and two-planet comparison table.
8. **KNOWLEDGE**: Local search engine, category filter, and Q&A guide.
9. **SETTINGS**: Hardware FPS/memory monitor, `LOW` / `MEDIUM` / `HIGH` graphics presets, audio synthesizer controls, and Projector Mode toggle.

## 4. Running the 13-Step Science Fair Projector Demo
Click **▶ Demo Mode** in the top bar (or inside **Settings**) to automatically enable high-contrast **Projector UI** and step through the 13-stage demonstration sequence:
1. Launch ATLAS & Starfield
2. Constellations Overlay
3. Solar System Overview
4. Select Earth
5. Fly Around Earth & Moon
6. Compare Earth with Jupiter in Laboratory
7. Travel to Saturn
8. Inspect Saturn's Rings
9. Enter the Jupiter Galilean Moon System (Europa)
10. Open Deep Space Catalogue (Orion Nebula M42)
11. Explore the Milky Way Disk & Solar System Position
12. Launch Mission 1: Earth-to-Mars Transfer
13. Return to Cinematic Universe Overview
